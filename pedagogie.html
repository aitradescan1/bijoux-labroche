Pourquoi un bijou coûte un peu d'argent ?

Salut ! Quand on fabrique un bijou, il faut payer quelques choses. Même si maman ou papa paye une partie, c'est bien de comprendre pourquoi.

Les 3 choses qui coûtent

  • Le matériel : tiges, breloques, chaîne, fil. Ce sont les petites pièces que l'on utilise pour créer le bijou.
  • Les outils : perceuse, limes, etc. Ces outils coûtent plus cher, mais on partage leur prix sur beaucoup de bijoux (on appelle ça « amortir »).
  • Les consommables : colle, un peu d'électricité, résine — des petites choses qu'on utilise à chaque bijou.

Exemples simples (en dollars canadiens)

Voici des exemples pour expliquer avec des nombres faciles :

  • Boucle d'oreille (la paire) : matière 0,78$ + outil (partagé) 0,08$ + colle+énergie 0,10$ = 0,96$
  • Collier : matière 4,89$ + outil 0,08$ + colle+énergie 0,10$ = 5,07$
  • Bracelet : matière 4,16$ + outil 0,08$ + colle+énergie 0,10$ = 4,34$

Comment on calcule (en 3 étapes faciles)

  1. On additionne tout le matériel utilisé pour le bijou.
  2. On ajoute une petite part du coût des outils (par exemple 0,08$ si on partage le coût sur beaucoup de bijoux).
  3. On ajoute un petit montant pour la colle et l'électricité (par exemple 0,10$).
